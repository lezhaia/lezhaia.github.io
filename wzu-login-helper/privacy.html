WZU 登入輔助工具 隱私權政策

最後更新日期:2026 年 11 月 25 日

本政策說明 Chrome 擴充功能「WZU 登入輔助工具」(以下簡稱「本擴充功能」)如何處理使用者資料。

資料收集

本擴充功能不收集、不儲存、不傳送任何個人資料或使用者資料,包括但不限於:

  • 帳號、密碼或其他登入資訊
  • 瀏覽紀錄、網頁內容
  • 裝置資訊、位置資訊
  • 使用統計或分析資料

運作方式

本擴充功能僅在文藻外語大學單一登入頁(https://sso.wzu.edu.tw/)執行,於使用者的瀏覽器本機讀取登入頁上顯示的驗證碼,並帶入同一頁面的驗證碼欄位。所有處理皆在使用者的瀏覽器內完成,不會連線至任何其他伺服器。

第三方分享

由於本擴充功能不收集任何資料,因此不會出售、轉讓或與任何第三方分享使用者資料。

權限說明

本擴充功能僅要求在 sso.wzu.edu.tw 網域執行內容腳本的權限,不要求其他網站或瀏覽器功能的存取權限。

非官方聲明

本擴充功能為個人製作,並非文藻外語大學官方產品,亦未獲該校背書。

政策變更

若本政策有所變更,將更新於本頁面並修改上方的最後更新日期。

聯絡方式

如有任何問題,請透過 Chrome 線上應用程式商店本擴充功能頁面上的開發者聯絡信箱與我們聯繫。

Privacy Policy — WZU 登入輔助工具 (WZU Login Helper)

Last updated: November 25, 2026

This extension does not collect, store, or transmit any personal or user data, including credentials, browsing history, device information, or usage analytics.

It runs only on the Wenzao Ursuline University single sign-on page (https://sso.wzu.edu.tw/). It reads the verification code displayed on that page and enters it into the verification code field on the same page. All processing happens locally in the user's browser; the extension does not connect to any other server.

Because no data is collected, no data is sold, transferred, or shared with third parties.

This extension is an independent personal project and is not an official product of, or endorsed by, Wenzao Ursuline University.

For questions, please use the developer contact email listed on the extension's Chrome Web Store page.
